# SHOW/RIFT

**Screenshots are not a story. Make people click.**

SHOW/RIFT is a local-first product story studio. It turns screenshots into a clickable product walkthrough with scenes, hotspots, captions and launch-ready exports.

![SHOW/RIFT preview](https://dummyimage.com/1400x720/101010/d6ff3f&text=SHOW%2FRIFT+Product+Story+Studio)

## Why it is useful

- Build a visual demo from screenshots without a design tool.
- Add hotspots that explain the exact part people should notice.
- Present the walkthrough in a clean player mode.
- Export a standalone HTML demo, a README block or a JSON backup.
- Keep everything local in the browser: no login, no backend, no upload.

## Quick Start

Open `index.html` in your browser.

For the repository check:

```bash
npm run check
```

## What You Can Export

| Export | Use it for |
| --- | --- |
| HTML | Offline clickable demo |
| README | GitHub launch section |
| JSON | Backup or continue later |

## Privacy

The app stores your work in `localStorage`. Your images and project data stay on your device unless you export and share them yourself.
